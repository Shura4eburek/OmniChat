# Pixel HUD UI: дизайн

Дата: 2026-10-03
Статус: согласовано в брейнсторминге, ждёт ревью спеки
Подпроект 1 из 2. Подпроект 2 — визуальные фишки в мире: облачка, индикатор набора и прочее.

## Цель

Переделать весь интерфейс OmniChat в единый стильный пиксельный HUD, чтобы мод выделялся на Modrinth. Попутно закрывается #47: экран настроек не помещается в маленькие окна.

Критерии успеха:
- экран настроек и все всплывающие элементы мода выглядят в одном бирюзовом HUD-стиле;
- на окне 854×480 при любом масштабе интерфейса ничего не выходит за экран;
- у каждого голоса есть портрет и карточка, даже если владелец сервера ничего не оформлял;
- голос можно прослушать до выбора, а нескачанный скачать прямо из карточки.

## Визуальный стиль

Ориентир — «тактический HUD» по референсу пользователя:
- тёмная полупрозрачная панель поверх мира;
- тонкая рамка с уголками-скобками;
- заголовок в разрядку;
- плитки-иконки с бейджами;
- правая панель деталей;
- строка статуса и строка подсказок внизу.

Утверждённые макеты: `.superpowers/brainstorm/*/content/hud-style.html`, вариант «бирюзовый».

| Токен | Значение |
|---|---|
| Акцент | `#35E0C8` |
| Акцент приглушённый (рамки, разделители) | `#35E0C8` @ 45 % |
| Фон панели | `#0A080C` @ ~86 % |
| Фон плитки | `#15111A` |
| Текст основной | `#D9D4DC` |
| Текст вторичный | `#9A93A0` |
| «Ок» | `#59E36B` |
| «Загрузка/внимание» | `#FFCF4A` |

Шрифт ванильный. Рамки толщиной 1 px (в масштабе GUI), уголки-скобки 2 px.

## Архитектура (клиент, пакет `client/ui/`)

| Юнит | Ответственность |
|---|---|
| `HudTheme` | Палитра, метрики. Примитивы: `frame` (рамка и уголки), `divider`, `spacedTitle`, `badge` |
| `HudButton`, `HudToggle`, `HudSlider` | Базовые контролы. Наследуют `ClickableWidget`, поэтому работают клавиатурная навигация и narration |
| `TabBar` | Вкладки «Голос / Звук / Облачка», переключение кликом и клавишами 1–3 |
| `VoiceTile` | Плитка: портрет и бейдж (✓ выбран, ↓ не скачан, % загрузка, ! ошибка) |
| `StatusLine` | Строка статуса: текст слева, состояние справа с цветом |
| `OmnichatScreen` | Заменяет `OmnichatSettingsScreen`. Шапка, `TabBar`, область вкладки, подвал с подсказками. Адаптивный размер |
| `VoiceTab` | Сетка `VoiceTile` и карточка выбранного голоса: портрет, имя, метаданные, описание, осциллограмма, слайдер спикера для мультиспикерных моделей (#42), кнопка «Скачать · N MB», статус |
| `AudioTab` | Громкость, скорость, эффект робота, озвучка своих сообщений, шёпот, `/me`, командные |
| `BubblesTab` | Облачка, скорость текста, облачка для шёпота, `/me` и командных, индикатор набора |
| `VoiceCatalog` | Единый список голосов. Сводит серверные записи, локальные модели и метаданные. Состояние: `INSTALLED`, `REMOTE`, `DOWNLOADING(pct)`, `FAILED(reason)` |
| `PortraitGenerator` | Детерминированный пиксельный портрет 16×16 из хэша имени модели: симметричная маска, палитра из хэша |
| `HudToast` | Тосты в стиле HUD поверх ванильного `ToastManager` |
| `DownloadProgressHud` | Перерисован в стиле HUD: список загрузок с полосой, «33 / 78 MB» и пометкой «в очереди» |

### Раскладка

- Ширина панели: `min(screenWidth − 16, 420)`, высота: `min(screenHeight − 16, 260)`, в масштабированных GUI-пикселях. Панель центрируется.
- Число колонок в `VoiceTab` считается от ширины левой части. Карточка занимает остаток.
- Если по высоте не помещается, сетка голосов прокручивается колесом. Карточка, вкладки и подвал всегда видны.
- Минимальный поддерживаемый размер: 854×480 при масштабе «авто». Его проверяют тесты раскладки.

## Метаданные голосов и протокол

### Файлы в папке модели (необязательные)

`voice.json`:
```json
{ "name": "Денис", "description": "Спокойный мужской голос", "language": "ru",
  "gender": "male", "sample": "Привет, я Денис." }
```
`portrait.png`: PNG 16×16 или 32×32, не больше 8 КБ.

Лимиты: `name` до 32 символов, `description` до 200, `sample` до 120, `language` до 8. Неизвестные поля игнорируются. Битый JSON или PNG пропускается с warn-логом, в этом случае используется запасной вариант.

### Сервер

- `VoiceRegistry` при сканировании (старт и `/omnichat reload`) читает метаданные и считает размер папки модели.
- Новый `VoiceCatalogS2CPayload` заменяет `ModelListS2CPayload`. Содержит список записей `{model, name, description, language, gender, sizeBytes, portrait(byte[] ≤ 8 КБ, может быть пустым)}`, не больше 64 записей.
- Отправляется после успешного рукопожатия и после `/omnichat reload`.
- `ProtocolVersionPayload.PROTOCOL_VERSION` поднимается до 2.

### Клиент

- `VoiceCatalog` хранит серверные записи. Локальные модели читает с диска через тот же парсер. Это нужно для одиночной игры и голосов, которых нет на сервере.
- Портрет превращается в `NativeImageBackedTexture` с id `omnichat:portrait/<sha1(model)>`. Текстуры освобождаются при отключении от сервера и при обновлении каталога.
- Нет портрета или он битый: используется `PortraitGenerator`. Нет имени: используется имя папки.
- Протокол несовместим: «Голос» показывает только локальные модели, в `StatusLine` предупреждение.

## Поведение

### Применение
- Кнопки Apply нет.
- Клик по установленному голосу сразу делает его активным: `modelPath` сохраняется, на сервер уходит `VoiceSelectionC2SPayload`, `TtsService` пересобирает движок.
- Клик по нескачанному голосу выделяет его. В карточке появляется кнопка «Скачать · N MB». После установки голос можно выбрать.
- Слайдеры и переключатели на вкладках «Звук» и «Облачка» применяются сразу. Конфиг сохраняется при закрытии экрана.

### Ввод
- ЛКМ выбирает. ПКМ по установленному голосу включает прослушивание.
- Tab и стрелки перемещают фокус, Enter выбирает, 1–3 переключают вкладки, O или Esc закрывают экран.
- Подвал показывает подсказки текущей вкладки.

### Прослушивание
- Фраза `sample` (или стандартная локализованная) синтезируется локально выбранным голосом и играет без позиционирования.
- Осциллограмма в карточке отражает реальную амплитуду (RMS окнами).
- Новое прослушивание прерывает предыдущее.
- Для нескачанного голоса прослушивания нет, вместо него подсказка.

### Анимации (сдержанные)
- Панель проявляется за 150 мс.
- Плитка под курсором подсвечивается рамкой.
- Бейдж загрузки показывает проценты.
- Курсор в заголовке мигает раз в секунду.
- Звук ванильного клика.

### Тосты
- «Голос скачан»
- «Загрузка не удалась: причина»
- «TTS отключён: нет рабочей модели»
- «Сервер с другой версией OmniChat»

Позиция в правом верхнем углу, около 5 секунд. Существующие сообщения в чат об этих событиях заменяются тостами.

### Локализация
Все строки идут через ключи `en_us` и `ru_ru`, без `Text.literal`.

## Ошибки

| Ситуация | Поведение |
|---|---|
| Нет `voice.json` / `portrait.png` | Имя папки и автопортрет |
| Битые метаданные | Warn-лог на сервере, запасные значения |
| Загрузка упала | Бейдж «!», причина в статусе карточки, тост |
| Модель не грузится движком | Тост «TTS отключён» или откат на fallback, как сейчас в `TtsService` |
| Несовместимый протокол | Только локальные голоса и предупреждение в статусе |

В проекте пока нет тестов: нужно добавить JUnit 5 (`testImplementation`) и source set `src/test`. Тесты без запуска игры:

- раскладка (чистая функция «размер экрана → прямоугольники») на 854×480, 1280×720 и 1920×1080 при масштабах 1–4: ничего не выходит за экран;

- ручной прогон: скачивание из карточки, тосты, прослушивание.
