# omnivoice — синтетический датасет через клонирующую модель: дизайн

Дата: 2026-10-04
Статус: согласовано в брейнсторминге, ждёт ревью спеки
Ишью: #60

## Цель

У многих персонажей мало реплик: у Артаса 22 фразы, ~48 с. Дообучение Piper на таком объёме упирается в потолок: MOS и mel перестают расти после ~800 эпох, тембр не дотягивает. Решение — zero-shot клонирующая модель-«учитель» (XTTS v2): по нескольким оригинальным фразам она озвучивает 10–30 минут разнообразного текста голосом персонажа, а Piper учится на синтетике вместе с оригиналом.

Пользователи: автор мода и другие люди, которые берут omnivoice с GitHub. Инструмент не монетизируется; мод на Modrinth распространяется без инструмента обучения.

Критерий успеха (из ишью): голос, обученный на синтетике + оригинале, на слух заметно ближе к персонажу, чем обученный только на оригинальных фразах, при сравнении на одних и тех же тестовых фразах.

## Решения, принятые в брейнсторминге

- **Модель:** сменный «учитель» за общим интерфейсом; первая и пока единственная реализация — XTTS v2 (форк `coqui-tts`). F5-TTS можно добавить позже, когда для русского будет надёжный чекпойнт.
- **Лицензия:** XTTS v2 — CPML (некоммерческая). Подходит, потому что инструмент и голоса не монетизируются. В README omnivoice указать: голоса, обученные с синтетикой XTTS, — только для некоммерческого использования.
- **Язык:** сначала русский; английский — позже, тем же механизмом (свой файл корпуса).
- **Тексты:** смесь — открытый корпус (CC0) для разнообразия звуков плюс фразы пользователя в стиле персонажа.
- **Ручная работа:** автоматический фильтр плюс выборочная проверка спорных фраз пользователем.
- **Окружение:** отдельное Python-окружение в той же WSL-среде omnivoice (`/opt/omnivoice/xtts`): у XTTS и piper разные требования к версиям библиотек, а GPU и установщик общие.

## Данные проекта

Новая папка проекта `synth/`; оригинальные `segments/` и `metadata.csv` не меняются.

- `synth/wavs/synth_NNNN.wav` — сгенерированные фразы. XTTS выдаёт 24 кГц; `xtts_gen.py` сразу приводит их к частоте проекта (`sample_rate`, обычно 22 050 Гц), моно, 16 бит — как оригинал.
- `synth/synth.json` — состояние синтетики:
  - `refs`: id оригинальных фраз-образцов;
  - `items`: по каждой фразе `id`, `text`, `source` (`corpus` | `user`), `status` (`pending` | `done` | `failed`), `duration`, `heard` (что распознал Whisper), `cer`, `verdict` (`accepted` | `suspect` | `rejected` | `unchecked`), `reasons` (коды причин), `dropped` (итоговое решение: не брать в обучение), `manual` (решение пользователя, перекрывающее автоматическое).
- `synth/lines.txt` — фразы пользователя в стиле персонажа, по одной на строку.

Синтетику можно стереть целиком и сгенерировать заново, оригинал не пострадает.

В `project.toml` новый шаг `synth` в `STEPS` между `check` и `train`. Шаг необязательный: обучение не требует его завершения.

## Поток данных

1. **Образцы голоса.** По умолчанию — 3–5 оригинальных фраз: не выкинутые, без меток, самые длинные в пределах 3–12 с, суммарно до ~30 с. Пользователь может убрать образец или подобрать заново.
2. **План.** Фразы пользователя (`lines.txt`) идут первыми; затем из корпуса добирается объём до заданного числа минут (по умолчанию 15). Длительность фразы оценивается по скорости речи оригинала (символов в секунду, медиана по не выкинутым фразам).
3. **Генерация.** `XttsTeacher` пишет задание (JSON: образцы, фразы, язык, папка) и запускает `xtts_gen.py` в WSL-окружении XTTS. Скрипт пишет wav и строки прогресса `ITEM n/N <id>`.
4. **Фильтр.** Whisper (тот же, что в «Нарезке») распознаёт каждую сгенерированную фразу; `synth_check` выносит вердикт (см. ниже).
5. **Обучение.** Набор для Piper: оригинальные фразы, повторённые `вес` раз (по умолчанию ×3), плюс принятая синтетика. Piper читает аудио из одной папки, поэтому перед обучением собирается `train/audio/` из жёстких ссылок на `segments/*.wav` и `synth/wavs/*.wav` (если жёсткая ссылка невозможна — копия).

## Модули

| Модуль | Ответственность |
|---|---|
| `omnivoice/corpus.py`, `omnivoice/data/corpus_ru.txt` | Корпус (~5 000 предложений Common Voice ru, CC0: 4–20 слов, без цифр, латиницы, аббревиатур и повторов). Выбор фраз на N минут жадным покрытием буквенных биграмм; фразы пользователя — вне очереди. |
| `omnivoice/teacher.py` | Интерфейс `Teacher.generate(refs, items, language, out_dir, on_line) -> код`; реализация `XttsTeacher` (WSL). Проверка готовности окружения XTTS. |
| `omnivoice/piper_compat/xtts_gen.py` | Работает внутри WSL в окружении XTTS: читает задание, генерирует, пишет wav и прогресс. Запускается из папки проекта через `/mnt/c` (как `fit.py`), без переустановки среды. Пропускает фразы, у которых wav уже есть (догенерация). |
| `omnivoice/synth.py` | Хранилище `synth/`: загрузка и сохранение `synth.json`, выбор образцов, построение плана, применение итогов генерации и проверки, принять / выкинуть / вернуть фразу, сводка. |
| `omnivoice/synth_check.py` | Вердикт по фразе: расхождение текста, длительность, паузы, клиппинг, пределы длины. Чистые функции над аудио и текстом. |
| `wsl_setup.sh` / отдельный шаг, `deps.py` | Необязательный шаг установки: окружение `/opt/omnivoice/xtts` с `coqui-tts` и CUDA-сборкой torch, собственная метка версии; скачивание весов XTTS v2 при первом запуске. Строка «Синтетика (XTTS v2)» с пометкой «необязательно» в чек-листе «Установки». |
| `dataset.piper_csv`, `train.py` | Набор для обучения с весом оригинала и принятой синтетикой; сборка `train/audio/`; `--data.audio_dir` указывает на неё. |
| UI: `SynthRunner`, раздел «Синтетика» | Генерация в фоне (как `TrainRunner`): прогресс, журнал, мягкий «Стоп»; страница и строка на «Обучении». |

Связи: UI → `synth` (план, задание) → `teacher` (генерация в WSL) → `synth_check` (Whisper) → `synth.json` → `dataset.piper_csv` при обучении.

## Фильтр брака

Текст сравнивается после нормализации: нижний регистр, `ё`→`е`, без знаков препинания, пробелы схлопнуты. `cer` — расстояние Левенштейна по символам, делённое на длину заданного текста.

| Проверка | Принято | Спорно | Брак |
|---|---|---|---|
| `cer` | ≤ 0.10 | 0.10–0.30 | > 0.30 |
| Длительность / ожидаемая | 0.6–1.7 | < 0.6 или 1.7–2.5 | > 2.5 |
| Самая длинная пауза внутри (тишина ниже −40 дБ относительно пика) | ≤ 1.2 с | > 1.2 с | — |
| Клиппинг (доля выборок с \|x\| ≥ 0.999) | ≤ 0.5% | > 0.5% | — |
| Длина | 0.8–15 с | — | вне пределов |

Итог — худший вердикт по проверкам; причины хранятся кодами и показываются по-русски. Брак получает `dropped = true` сразу; спорное ждёт решения пользователя и по умолчанию **не** идёт в обучение; принятое идёт. Ручное решение (`manual`) всегда важнее автоматического и сохраняется при повторной проверке.

## Ошибки и прерывания

- **Нет окружения XTTS:** на странице жёлтая карточка с кнопкой «К установке»; кнопка «Сгенерировать» неактивна.
- **«Стоп»:** мягкий, как у обучения: файл-флаг `synth/STOP`, `xtts_gen.py` заканчивает текущую фразу и выходит; через 60 с без выхода — принудительно. Готовые фразы остаются `done`, недоделанные — `pending`; «Догенерировать» доделывает только их.
- **Ошибка на одной фразе:** `failed` с текстом ошибки, генерация продолжается; сводка показывает число неудач.
- **Нет Whisper:** вердикт `unchecked`, в обучение такие фразы не идут; на странице подсказка поставить пакеты подготовки.
- **Повторная генерация** (другие образцы или минуты) перестраивает план: фразы с ручным решением и уже принятые с теми же образцами сохраняются, остальные помечаются `pending`.

## Интерфейс

Страница «Синтетика» (пункт сайдбара и плашка шага между «Проверкой» и «Обучением», плашка помечена как необязательная):

1. Карточка «Нужна установка XTTS v2 (≈ 3–4 ГБ)» с кнопкой «К установке» — только если окружения нет.
2. Настройки: «Образцы голоса» (карточки с HUD-плеером, ✕ и «Подобрать автоматически»), «Сколько минут синтетики» (15), «Свои фразы в стиле персонажа» (поле, по строке на фразу).
3. Кнопки «Сгенерировать» / «Стоп» / «Догенерировать» с состояниями как у обучения (неактивны, когда не имеют смысла; двойной клик игнорируется).
4. Прогресс и журнал: «Генерирую 87/240 · осталось ≈ 6 мин»; журнал с автопрокруткой (`log-box`).
5. Сводка: «принято N (M мин) · спорно · брак · не удалось».
6. Список фраз с фильтром «Спорные / Принятые / Брак» (по умолчанию спорные): карточки как во «Фразах» — ▶ (общий плеер внизу), текст, «Whisper услышал: «…»», причина; справа ✓ принять и ✕ выкинуть (↺ у выкинутых).

На «Обучении»: строка «Синтетика: N фраз · M мин», галочка «Использовать при обучении» (включена, если есть принятая синтетика) и поле «Вес оригинала» (×3).

Внешний вид следует принятым правилам интерфейса: HUD-карточки и плеер, кнопки 40 px, текст по краю рамок, ровные отступы 20 px; проверка при увеличении в 1× и 3×.

## Проверка

Автотесты (без XTTS и Whisper — заглушки, как сейчас для piper):
- корпус: число фраз на N минут, фразы пользователя первыми, рост покрытия биграмм, фильтр корпуса;
- `synth.json`: план, догенерация, применение результатов, ручные решения переживают повторную проверку;
- `synth_check`: пороги на искусственных сигналах (тишина внутри, клиппинг, длительность) и текстах (`cer`);
- набор для Piper: вес оригинала, только принятая синтетика, жёсткие ссылки и копия как запасной путь;
- команды запуска `xtts_gen.py`, мягкий «Стоп», обработчики UI.

Ручная проверка: установка окружения XTTS в WSL; генерация ~2 минут на копии Arthas; фильтр; страница в браузере при 1× и 3×; «Стоп» и «Догенерировать».

Приёмка пользователем: ~15 минут синтетики, обучение от `ruslan`, сравнение на слух с моделью без синтетики на одних и тех же фразах.

## Не входит в первую версию

Английский язык, F5-TTS, проверка сходства голоса отдельной моделью (speaker embedding), автоматическое сочинение фраз в стиле персонажа, Colab-путь для синтетики.
